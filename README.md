# bike-sharing-analysis
# Bike Sharing Demand Analysis

## Overview
This project explores hourly bike-sharing data to identify patterns in rental demand and examine how factors such as weather, season, and working days relate to bike usage. Using Python, I cleaned and analyzed the dataset, calculated probabilities and correlations, and created visualizations to better understand rental trends.

## Objectives
- Identify patterns in bike rental demand across different conditions
- Examine relationships between weather, temperature, and rental activity
- Compare rental demand on working and non-working days
- Calculate conditional probabilities of high rental demand
- Explore sampling variability and uncertainty using bootstrap methods

## Tools and Libraries
- **Python** for data processing and analysis
- **pandas** for data cleaning and manipulation
- **NumPy** for numerical calculations
- **Matplotlib and Seaborn** for data visualization

## Dataset
The project uses an hourly bike-sharing dataset containing rental counts from 2011 and 2012, along with information about weather conditions, temperature, humidity, season, and working days. 
https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

## Methodology

### 1. Data Cleaning and Preparation
- Inspected the dataset for missing values, duplicates, and inconsistent data types
- Renamed columns to improve readability
- Converted dates and standardized categorical variables
- Created additional variables for analysis

### 2. Exploratory Data Analysis
- Examined rental demand across weather conditions, seasons, and working days
- Calculated descriptive statistics and correlations
- Created bar charts and histograms to visualize rental patterns

### 3. Probability and Statistical Analysis
- Classified rental periods as high or low demand based on average rental counts
- Calculated empirical and conditional probabilities
- Used sampling and bootstrap methods to examine variability in estimates

## Visualizations
The project includes visualizations created with Matplotlib and Seaborn to illustrate rental demand patterns, compare groups, and explore relationships between variables.

## Key Takeaways
This project strengthened my experience with data cleaning, exploratory data analysis, probability, and statistical interpretation. It also gave me experience using Seaborn independently to create and interpret visualizations from real-world data.
